Add a deck

One card per line, quantity first. A line reading SIDEBOARD, COMMANDER, or MAYBEBOARD starts that section. Set codes in brackets pick a printing, like 4 Lightning Bolt [2x2]. Card data and art come from Scryfall.

Two-player table

Your buddy types the code on his end. The code only introduces the two phones — after that the connection is direct.

Some cards didn't match

Usual causes: a typo, a name that needs both halves of a double-faced card, or a printing whose set code Scryfall spells differently. Editing the name usually fixes it — the set code is optional and can be deleted.

Backup

Decks live in this browser only. Clearing site data wipes them, and they don't follow you to another phone. A backup file is the fix for both.

The deck file restores everything including card data. The decklist file is plain text you can paste anywhere or hand to your buddy.
