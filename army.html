Hints, FAQ, and how this page works

Casual / learning lists for this table. Purple names are fan-sourced stats. Gold / normal names were checked against a pack or card. Red is points only.

How do I start a list?

New list → name it → pick battle size (Incursion 1000 / Strike Force 2000 / Onslaught 3000). Onslaught DP on this table is a house rule. Pick one faction. Add units. Detachments are optional until you care about rules.

Can I mix factions?

No. One army faction per list. Tyranids stay with Tyranids. Space Marines stay with Space Marines. Forgefather’s Seekers also locks the list to Salamanders — no Ultramarines characters in that detachment.

What do the colors mean?

Normal: accepted from an official pack/card. Purple · fan: Wahapedia fill for casual play — check the app if a fight depends on it. Red · pts only: cost only, no stat line yet. Do not drop red units and expect shooting to work.

Points, copies, and “3rd+”

MFM often charges more for the 3rd copy of the same datasheet, or for a bigger model count. Change the model count and the quote should follow. Two identical units in the list are copy 1 and copy 2. Battle size also caps how many copies you may take.

What is DP?

Detachment Points. Battle size gives a budget (2 / 3 / 4 on this table). Each detachment costs 1–3 DP. Tick only what you are using. Enhancements are a count until those cards are ingested — type how many you took; cap is on the size.

Weapons and model counts

Set how many models are in the unit, then how many carry each gun. That is for the table and for points bands. Optional wargear is not a full options tree yet — pick the sheet that already matches (Eradicators vs Eradicators with Heavy Bolters).

Salamanders starter

Search “salamanders” or open Space Marines. Useful pieces: Vulkan He’stan (official card, points still review), Adrax Agatone, Infernus, Aggressors, Eradicators, Firestrike. Detachment: Forgefather’s Seekers (2 DP) or Firestorm Assault Force (2 DP). Land Raider Redeemer is not in the catalog yet.

Where does this list go?

Saved on this device. Load it from the 40K table when you start a game — only that army’s units should appear, not Demo, once the list has models. Need the same list on a second PC? Export is not built yet; rebuild or copy the device.
